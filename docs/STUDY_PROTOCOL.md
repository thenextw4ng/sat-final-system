Study in three short blocks. Reveal the meaning, recall it without looking, then use the source example sentence. Mark a word mastered only after independent recall.

## Original question bank: 21 parts / 1,234 questions

Parts 01–20 contain 60 items each, in original question-ID order. Part 21 contains questions 1201–1234 (34 items). The 10-day / 600-item core plan uses Parts 01–10, one part per day. Parts 11–21 remain available for continuation or review.

## Quiz sequence

1. Answer the entire part before revealing keys.
2. Finish the part to reveal the source answer key and explanation.
3. Review wrong, guessed, and uncertain answers.
4. Retake only after completing the review.

Any new passages or newly written practice questions must live in a separate `GENERATED_PRACTICE` collection, never in the original-bank parts.
