# Data directory

## Committed full content

- `vocabulary/part-01.json` … `part-08.json`: full vocabulary records (word, part of speech, Indonesian meaning, English definition, example).
- `question-markdown/part-01.md` … `part-21.md`: complete copied source questions with passages/prompts, A–D choices, correct answers, and explanations.

The browser application loads these files directly. The question files are Markdown so they are readable and copyable as full source questions. Part counts: vocabulary 57,57,57,57,57,57,57,56; questions 20×60 plus 34.

The importer can regenerate these partitions from the two source files in `sources/`.
